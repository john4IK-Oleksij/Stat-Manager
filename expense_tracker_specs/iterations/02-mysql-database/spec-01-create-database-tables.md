# SPEC 02.1 — Створити базу даних і таблиці

## Мета
Створити структуру MySQL відповідно до SQL у вихідному PDF.

## Вимоги
- База `expense_tracker`, кодування `utf8mb4`.
- Таблиці `categories` та `expenses`.
- Типи, первинні ключі, `UNIQUE`, `CHECK` та зовнішній ключ мають відповідати інструкції.
- Для `expenses.category_id` — `ON DELETE RESTRICT`.

## Робота асистента
- Перевірити SQL перед виконанням.
- Пояснити призначення кожного обмеження.
- Не змінювати схему відносно PDF без окремого узгодження.

## Потрібна дія користувача — ОБОВ'ЯЗКОВО
- Виконати SQL у своєму MySQL-середовищі або надати доступний результат виконання.
- Підтвердити, що таблиці створені.

## Критерій завершення
Структуру перевірено командами `SHOW CREATE TABLE` або еквівалентом.
