# SPEC 02.3 — Додати тестові дані (за потреби)

## Мета
Додати приклади категорій і витрат із PDF для перевірки API.

## Робота асистента
- Звірити вставки з фактичною схемою.
- Врахувати унікальність `categories.name`.
- Підготувати безпечний спосіб уникнути повторного дублювання даних.

## Потрібна дія користувача
- Вирішити, чи потрібні тестові дані в локальній БД.
- Виконати SQL та повідомити результат.

## Критерій завершення
У БД є очікувані 4 категорії та 6 витрат або зафіксовано, що тестові дані не потрібні.
