# SPEC 02.2 — Створити користувача застосунку та права

## Мета
Налаштувати окремого MySQL-користувача для API.

## Вимоги
- Користувач `expense_app`@`127.0.0.1`.
- Права: `SELECT`, `INSERT`, `UPDATE`, `DELETE` на `expense_tracker.*`.
- Не використовувати адміністративний обліковий запис застосунку.

## Робота асистента
- Підготувати SQL-команди й пояснити їх.
- Перевірити, що права не ширші за потрібні.

## Потрібна дія користувача — ОБОВ'ЯЗКОВО
- Вибрати й задати пароль локально.
- Не надсилати пароль у чат, якщо в цьому немає потреби.
- Виконати SQL із облікового запису, що має право створювати користувачів і надавати привілеї.

## Уточнення джерела
У PDF є суперечність: вимога до пароля щонайменше 12 символів, але приклад використовує `111`. Не використовувати `111` як реальний пароль; перед реалізацією узгодити правило.

## Критерій завершення
Користувач застосунку має лише необхідні права та може підключитися до потрібної БД.
