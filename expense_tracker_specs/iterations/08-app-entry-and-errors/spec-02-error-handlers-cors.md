# SPEC 08.2 — Обробники помилок і CORS

## Мета
Налаштувати контрольовані HTTP-помилки та CORS.

## Вимоги з PDF
- `PoolError` → `503`.
- MySQL duplicate key (1062) → `409`.
- FK restrict (1451) → `409`.
- Інші неочікувані помилки → `500` без SQL-подробиць у відповіді.
- CORS у PDF має два варіанти: wildcard `*` і закоментований список локальних origin.

## Робота асистента
- Реалізувати обробники та безпечне логування.
- Не повертати клієнту SQL або внутрішні деталі.

## Потрібна дія користувача
- Вибрати CORS-конфігурацію під своє середовище: локальна розробка чи інше.
- Перевірити поведінку конфліктів і недоступної БД.

## Критерій завершення
Коди помилок передбачувані, а відповіді не розкривають внутрішні подробиці.
