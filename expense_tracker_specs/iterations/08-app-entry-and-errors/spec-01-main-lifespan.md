# SPEC 08.1 — Точка входу та життєвий цикл

## Мета
Зібрати застосунок у `main.py`.

## Вимоги
- `lifespan` створює пул на старті й коректно звільняє ресурси при завершенні.
- Підключити три router-и: categories, expenses, stats.
- Кореневий `/` повертає `{"message": "Expense Tracker API"}`.

## Робота асистента
- Реалізувати точку входу відповідно до структури проєкту.
- Перевірити імпорти та відсутність циклічних залежностей.

## Потрібна дія користувача
- Запустити `uv run fastapi dev` та надати результат.

## Критерій завершення
Застосунок стартує, а всі маршрути зареєстровані.
