# SPEC 07.3 — HTTP-маршрути статистики

## Мета
Створити `app/routers/stats.py`.

## Маршрути
- `GET /stats/summary`
- `GET /stats/by-category?min_count=...`
- `GET /stats/by-month`

## Вимоги
- `min_count`: 0–1 000 000.
- Використовувати сервіс статистики та визначені response schemas.

## Потрібна дія користувача
- Викликати кожен endpoint і перевірити структуру JSON та значення.

## Критерій завершення
Усі три маршрути повертають валідні відповіді.
