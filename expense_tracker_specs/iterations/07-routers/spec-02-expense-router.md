# SPEC 07.2 — HTTP-маршрути витрат

## Мета
Створити `app/routers/expenses.py`.

## Вимоги
- CRUD витрат.
- Параметри списку: `q`, `category_id`, `sort_by`, `order`, `limit`, `offset`.
- `q`: 1–50 символів.
- `category_id`: 1–`2**63 - 1`.
- `sort_by`: `spent_on`, `amount`, `title`.
- `order`: `asc`, `desc`.
- `limit`: 1–100, типовий 20.
- `offset`: 0–100000, типовий 0.
- Перевіряти існування категорії при створенні або зміні категорії.

## Робота асистента
- Створити router, типізувати параметри та response models.
- Використовувати сервісний рівень.

## Потрібна дія користувача
- Перевірити валідні та невалідні запити в Swagger UI/HTTP-клієнті.

## Критерій завершення
CRUD і параметри списку працюють згідно з обмеженнями.
