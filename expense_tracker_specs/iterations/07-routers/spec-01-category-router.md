# SPEC 07.1 — HTTP-маршрути категорій

## Мета
Створити `app/routers/categories.py`.

## Маршрути
- `POST /categories/`
- `GET /categories/`
- `GET /categories/{category_id}`
- `PATCH /categories/{category_id}`
- `DELETE /categories/{category_id}`

## Вимоги
- Викликати сервіс, а не репозиторій напряму.
- Статуси: `201` для створення, `204` для видалення, `404` для відсутнього запису, валідація FastAPI/Pydantic — `422`.
- Конфлікт унікальної назви обробляється згідно з погодженим обробником помилок.

## Потрібна дія користувача
- Перевірити маршрути у Swagger UI або HTTP-клієнті після запуску застосунку.

## Критерій завершення
Контракти маршрутів і статус-коди відповідають PDF.
