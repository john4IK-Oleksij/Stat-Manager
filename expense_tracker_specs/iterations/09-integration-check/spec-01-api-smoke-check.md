# SPEC 09.1 — Перевірка запуску та всіх endpoint-ів

## Мета
Підтвердити наскрізну роботу API.

## Перевірити
- Запуск сервера.
- `/` та всі endpoint-и categories, expenses, stats.
- CRUD категорій і витрат.
- Фільтри, сортування, пагінацію.
- Статистику.
- `201`, `204`, `404`, `409`, `422`, `503` у відповідних сценаріях.

## Робота асистента
- Надати послідовність запитів для перевірки.
- Допомогти інтерпретувати фактичні відповіді та помилки.

## Потрібна дія користувача — ОБОВ'ЯЗКОВО
- Запустити API та виконати запити локально.
- Надати відповіді або скриншоти/текст помилок без секретів.

## Критерій завершення
Усі основні сценарії перевірені; дефекти записані й виправлені або явно задокументовані.
