# SPEC 01.2 — Ініціалізувати Python-проєкт через uv

## Мета
Забезпечити базову конфігурацію Python-проєкту згідно з інструкцією.

## Робота асистента
- Визначити, чи потрібна команда `uv init`, з огляду на наявний стан.
- Якщо ініціалізація вже виконана, не запускати її повторно без потреби.
- Перевірити очікувані файли конфігурації.

## Потрібна дія користувача
- Виконати запропоновані команди у своєму терміналі, якщо немає доступу до середовища виконання.
- Надіслати помилки або результат перевірки.

## Критерій завершення
Структура проєкту створена або підтверджено, що вона вже коректна.
