# SPEC 01.3 — Встановити залежності

## Мета
Додати залежності, зазначені у вихідній інструкції.

## Вимоги
- `fastapi[standard]`
- `mysql-connector-python`

## Робота асистента
- Перевірити поточні залежності.
- Підготувати мінімальну зміну конфігурації через `uv`.
- Перевірити узгодженість `pyproject.toml` і `uv.lock`, якщо lock-файл використовується.

## Потрібна дія користувача
- Запустити команду встановлення, якщо її не можна виконати в середовищі проєкту асистента.
- Підтвердити, що команда завершилася без помилок.

## Критерій завершення
Залежності встановлені та доступні у середовищі проєкту.
