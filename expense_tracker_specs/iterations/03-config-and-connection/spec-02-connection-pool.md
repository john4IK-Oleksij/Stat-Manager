# SPEC 03.2 — Пул MySQL-з'єднань і залежність `Conn`

## Мета
Реалізувати кероване отримання та повернення з'єднань.

## Вимоги з PDF
- Пул розміром 5.
- `utf8mb4`, заданий SQL mode, timeout 5 секунд.
- Вимкнути multi-statements через client flags.
- `get_conn`: отримати з'єднання, зробити rollback при винятку, закрити/повернути з'єднання у `finally`.
- Тип `Conn` через `Annotated` і `Depends`.

## Робота асистента
- Реалізувати `app/database.py`.
- Перевірити правильність життєвого циклу з'єднання.
- Не логувати пароль або повний рядок підключення із секретом.

## Потрібна дія користувача
- Запустити перевірку підключення у своєму середовищі.
- Надати текст помилки без паролів, якщо підключення не працює.

## Критерій завершення
Застосунок підключається до MySQL, а з'єднання повертаються до пулу навіть після помилки.
