# SPEC 05.3 — Репозиторій статистики

## Мета
Реалізувати SQL-агрегати статистики.

## Вимоги
- Загальна статистика.
- Статистика за категоріями.
- Статистика за місяцями.
- `LEFT JOIN` для збереження категорій без витрат.
- Фільтр `min_count`.
- Групування за місяцем через `DATE_FORMAT`, як у PDF.

## Робота асистента
- Створити `app/repositories/stats_repository.py`.
- Звірити назви та типи полів відповіді зі схемами.

## Потрібна дія користувача
- Звірити кілька результатів із тестовими даними, щоб підтвердити арифметику.

## Критерій завершення
Агрегати та групування відповідають даним у БД.
