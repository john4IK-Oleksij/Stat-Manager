# SPEC 05.2 — Репозиторій витрат

## Мета
Реалізувати SQL-доступ до `expenses`.

## Операції та правила
- Створення, отримання за ID, оновлення, видалення.
- Фільтрування за `category_id` та `q`.
- Пошук має екранувати `!`, `%`, `_` у `LIKE`.
- Сортування лише за дозволеними полями `spent_on`, `amount`, `title` і напрямками `asc`, `desc`.
- Пагінація `limit` і `offset`.
- Для динамічного `UPDATE` — білий список полів.
- Усі значення SQL — параметризовані.

## Робота асистента
- Створити `app/repositories/expense_repository.py`.
- Перевірити, що дані користувача не можуть стати довільним SQL-фрагментом.

## Потрібна дія користувача
- Виконати перевірки на тестових даних і передати фактичні помилки, якщо вони є.

## Критерій завершення
CRUD, фільтри, сортування та пагінація працюють відповідно до обмежень PDF.
