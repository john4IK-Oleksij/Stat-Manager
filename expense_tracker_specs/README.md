# Expense Tracker API — дрібні специфікації

Специфікації розбиті на невеликі, перевірювані задачі на основі вихідного PDF. Вони не є підтвердженням того, що код уже реалізований.

## Де потрібна участь користувача

**Обов'язкова/найважливіша участь:**
- **Ітерація 2:** виконати SQL у власному MySQL, створити користувача БД та задати пароль.
- **Ітерація 3:** заповнити локальний `.env` і перевірити підключення.
- **Ітерація 8:** обрати доречний варіант CORS для свого середовища.
- **Ітерація 9:** запустити API й реально виконати перевірки.

**Коротка перевірка після змін потрібна майже в кожній ітерації.** Асистент може підготувати код і команди, але не може підтвердити, що вони працюють у локальному Windows/MySQL-середовищі, доки користувач не виконає їх і не надасть результат.
